# Black Hole Explorer

An animated, interactive app for learning the parts of a black hole and what happens in each one.

**Open it:** https://khershlok.github.io/blackhole-explorer/

- Click any part (lensing, jets, accretion disk, photon sphere, event horizon, singularity) to learn about it
- 🧑‍🚀 Fall in tour: drop an astronaut towards the centre and watch time slow down
- Light paths that bend around the black hole, a size calculator and a quiz
